# Data source
- Dataset: UNSW-NB15 (Moustafa & Slay, UNSW Canberra Cyber Range Lab, 2015)
- Official page: https://research.unsw.edu.au/projects/unsw-nb15-dataset
- Mirror used: https://www.kaggle.com/datasets/mrwellsdavid/unsw-nb15
- Files: UNSW-NB15_1..4.csv (headerless, 2,540,047 rows total), NUSW-NB15_features.csv
  (column definitions), UNSW-NB15_LIST_EVENTS.csv; the train/test split files are not used.
- Downloaded: 2026-10-06 with `kaggle datasets download mrwellsdavid/unsw-nb15 --unzip`
- Not committed (size). Re-download with the command above.
